Software é o conjunto de programas e instruções que orienta o funcionamento do hardware. Um navegador, um editor de texto e um jogo são exemplos de aplicativos. O sistema operacional, como Linux ou Windows, gerencia memória, arquivos, dispositivos e a execução dos programas. Ele também oferece uma interface para o usuário interagir com a máquina. Os drivers permitem que o sistema se comunique com equipamentos específicos, como impressoras e placas de rede. Atualizações podem corrigir falhas, melhorar recursos e resolver problemas de segurança. Instalar programas de fontes confiáveis reduz riscos, mas não substitui outros cuidados. Hardware e software dependem um do outro: os componentes físicos executam as instruções criadas pelos programas.
